Repository onboarding

After adding and synchronizing a repository, expand Checkout setup under its card. Choose Clone new repository or Connect existing checkout. Commands use that repository's mirror path and selected branch.

Run clone commands from the parent directory of a new checkout; run existing checkout commands inside the application directory. Never run them inside the bare mirror. Review local changes and divergent commits before pulling. The Git Mirror does not push changes to Enterprise GitHub.
